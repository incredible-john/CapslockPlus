# CapslockPlus

CapslockPlus 是一个 Windows 托盘小工具，让 Caps Lock 变成便于单手操作的导航修饰键。按住 Caps Lock，再按下表中的按键即可发送对应的导航按键。

## 功能一览

| 组合键 | 功能 |
| --- | --- |
| Caps Lock + S | 左方向键 |
| Caps Lock + F | 右方向键 |
| Caps Lock + E | 上方向键 |
| Caps Lock + D | 下方向键 |
| Caps Lock + P | Home（行首） |
| Caps Lock + ; | End（行尾） |
| Caps Lock + U | Shift + Home（选择到行首） |
| Caps Lock + O | Shift + End（选择到行尾） |

## 使用方式

启动程序后，它会在系统托盘中运行。按住 Caps Lock 并按对应按键即可使用上述功能；Caps Lock 本身不会切换大小写。要退出程序，请右键单击托盘图标并选择“退出”。

## 运行环境

- Windows
- .NET 10
